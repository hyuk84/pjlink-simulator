# PJLink Simulator

[English](README.md) | **한국어**

실제 프로젝터 없이 PJLink 제어 프로그램을 테스트하기 위한 가짜 PJLink 프로젝터입니다.
TCP 4352를 열어 두고, 들어오는 명령을 **전부 로그로 찍고** PJLink Class 1 사양대로 응답합니다.

- 의존성 없음 - Node.js 20 이상만 있으면 됩니다.
- IP를 여러 개 주면 프로젝터 여러 대를 한 번에 흉내 냅니다.
- PJLink 인증(MD5), 예열/냉각 상태, 꺼진 상태의 `ERR3` 등 실제 장비 동작을 따릅니다.
- 확인용 클라이언트가 함께 들어 있어서 실제 프로젝터에 명령을 보내 볼 때도 쓸 수 있습니다.

## 실행

```bash
node src/server.mjs
```

```bash
# 프로젝터 3대, 비밀번호 인증, 파일 로그
node src/server.mjs --hosts 127.0.0.1,127.0.0.2,127.0.0.3 --password admin --log pjlink.log
```

| 옵션 | 기본값 | 설명 |
| --- | --- | --- |
| `--hosts` | `127.0.0.1` | 프로젝터 한 대당 IP 하나 (쉼표로 구분) |
| `--port` | `4352` | PJLink 포트 |
| `--password` | (없음) | 주면 PJLink 인증(MD5) 사용 |
| `--warmup` | `3` | 켜기 예열 / 끄기 냉각 시간(초). 그동안 `POWR ?`는 `3`/`2`, 다른 전원 명령은 `ERR3` |
| `--name` | `PJLink Simulator` | `NAME ?` 응답. 여러 대면 뒤에 `#1`, `#2`가 붙음 |
| `--lamp-hours` | `1234` | `LAMP ?` 응답 누적 시간 |
| `--idle-timeout` | `30` | 명령 없이 이 시간(초)이 지나면 연결 끊기 (사양값) |
| `--log` | (없음) | 콘솔과 함께 파일에도 로그 남기기 |

### 여러 대 흉내 내기

대마다 IP가 달라야 합니다. 같은 PC에서 테스트할 때는 루프백 주소를 쓰면 됩니다.

- Windows: `127.0.0.2`, `127.0.0.3` … 이 설정 없이 바로 됩니다.
- Linux: `127.0.0.0/8` 전체가 기본으로 루프백이라 바로 됩니다.
- macOS: 별칭을 먼저 추가해야 합니다 - `sudo ifconfig lo0 alias 127.0.0.2`

다른 PC의 제어 프로그램에서 접속하게 하려면 이 PC의 실제 IP를 `--hosts`에 주고, 방화벽에서 4352 인바운드를 허용합니다.

## 로그

```
2026-10-29 14:02:11.204 [127.0.0.1:4352] connected <- 127.0.0.1:53122
2026-10-29 14:02:11.205 [127.0.0.1:4352] TX -> 127.0.0.1:53122  PJLINK 0\r
2026-10-29 14:02:11.230 [127.0.0.1:4352] RX <- 127.0.0.1:53122  %1POWR 1\r  (hex 2531504f575220310d)
2026-10-29 14:02:11.230 [127.0.0.1:4352]    * power on -> warming up
2026-10-29 14:02:11.231 [127.0.0.1:4352] TX -> 127.0.0.1:53122  %1POWR=OK\r
2026-10-29 14:02:14.232 [127.0.0.1:4352]    * power -> on
```

- `RX`는 클라이언트가 보낸 원문입니다. `\r`, `\n`, `\0`을 눈에 보이게 바꾸고 hex도 같이 찍습니다 - 어떤 종료 문자를 쓰는지 확인할 수 있습니다.
- `TX`는 시뮬레이터가 보낸 응답입니다.
- `*` 줄은 시뮬레이터가 해석한 내용입니다(전원 변경, 인증 성공/실패, 지원하지 않는 명령 등).
- `connected` 줄조차 없으면 제어 프로그램이 이 주소/포트로 접속하지 않은 것입니다.
- 로그는 영어로만 나옵니다.

## 클라이언트

다른 터미널에서 명령을 직접 보내 볼 수 있습니다. 실제 프로젝터에 대고 써도 됩니다.

```bash
node src/client.mjs 127.0.0.1 "%1POWR 1" "%1POWR ?" "%1LAMP ?"
node src/client.mjs 127.0.0.1 "%1POWR ?" --password admin
```

```
RX  PJLINK 0\r
TX  %1POWR 1\r
RX  %1POWR=OK\r
TX  %1POWR ?\r
RX  %1POWR=3\r
TX  %1LAMP ?\r
RX  %1LAMP=1234 0\r
```

## 지원 명령 (Class 1)

| 명령 | 조회 `?` | 설정 |
| --- | --- | --- |
| `POWR` | `0` 꺼짐 / `1` 켜짐 / `2` 냉각 중 / `3` 예열 중 | `0` 끄기, `1` 켜기 |
| `INPT` | 현재 입력 (켜져 있을 때만) | `11` `12` `31` `32` `51` |
| `AVMT` | 현재 뮤트 상태 (켜져 있을 때만) | `10` `11` `20` `21` `30` `31` |
| `ERST` | `000000` | - |
| `LAMP` | `<누적시간> <켜짐 1/0>` | - |
| `INST` | `11 12 31 32 51` | - |
| `NAME` `INF1` `INF2` `INFO` | 고정 문자열 | - |
| `CLSS` | `1` | - |

응답 코드: `OK`, `ERR1` 없는 명령, `ERR2` 잘못된 값, `ERR3` 지금은 못 함(예열/냉각 중, 꺼진 상태의 입력 전환 등).
Class 2(`%2...`) 명령은 `ERR1`로 응답합니다.

인증을 켜면 접속 시 `PJLINK 1 <난수>`를 보내고, 첫 명령 앞에 붙은 `MD5(난수 + 비밀번호)`를 검사합니다.
틀리면 `PJLINK ERRA`를 보내고 연결을 끊습니다.
